# Datas-of-Santa-Elisa-and-Franca
Arquivos e dados de caminhamento eletrico e sensores de umidade.
Files and data from electrical resistivity profiling and moisture sensors.

Caminhamento elétrico: Dados da Fazenda Santa Elisa, em Campinas-SP,  Fazenda DaTerra, em Franca-SP.
ERT: Santa Elisa datas, Campinas- SP, Daterra Farm in Franca-SP.

Sensores de umidade e temperatura: Arquivos csv, das fazendas. Com os dados de umidades (m³/m³) e temperatura, para todos os sensores usados.
Humidity and temperature sensors: CSV files from the farms, containing humidity (m³/m³) and temperature data for all sensors used.
