# Datas-of-Santa-Elisa-and-Franca
Arquivos e dados de caminhamento eletrico e sensores de umidade.

Caminhamento elétrico: Dados da Fazenda Santa Elisa, em Campinas-SP. E da Fazenda DaTerra, em Franco-SP.
Sensores de umidade e temperatura: Arquivos csv, das fazendas. Com os dados de umidades (m³/m³) e temperatura, para todos os sensores usados.
