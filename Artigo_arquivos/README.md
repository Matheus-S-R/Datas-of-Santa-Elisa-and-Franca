##As pastas tem os dados usados na aquisição.

Com os códigos e dados usados e as demais linhas que não mostramos nas análises
Código "comparacasecoes_jl" é uma código na linguagem Julia, os demais códigos estão na linguagem do Matlab (arquivo.m)
Os códigos no Matlab estão separados em duas sub-pastas, uma para os sensores e outra com os dados das seções elétricas.
Os dados de seções estão no formato .stg e .dat, para facilitar leitura.
